Política de Privacidade

Transparência total sobre o tratamento e proteção dos seus dados pessoais.

1. Coleta de Dados Pessoais

Para viabilizar a entrega dos nossos colchonetes sustentáveis e manter você informado sobre o impacto do projeto Sleep Well, coletamos dados básicos fornecidos diretamente por você, tais como nome completo, CPF, e-mail, telefone e endereço de entrega.

2. Uso das Informações

As informações coletadas são utilizadas estritamente para as seguintes finalidades:

  • Processamento e envio dos pedidos realizados na plataforma.
  • Emissão de notas fiscais e relatórios de transparência social.
  • Comunicação sobre atualizações do pedido e suporte ao cliente.

3. Proteção e Segurança de Dados

Adotamos medidas técnicas e organizacionais de segurança para proteger seus dados pessoais contra acesso não autorizado, perda, alteração ou qualquer forma de tratamento inadequado, alinhados com as diretrizes da Lei Geral de Proteção de Dados (LGPD).

4. Compartilhamento com Terceiros

A Sleep Well não comercializa dados pessoais. O compartilhamento ocorre exclusivamente com parceiros estritamente necessários para a operação, como transportadoras para efetuar a entrega e gateways de pagamento para processamento das transações.

5. Seus Direitos

Você tem o direito de solicitar a confirmação da existência de tratamento, o acesso aos seus dados, a correção de dados incompletos ou a exclusão de suas informações da nossa base de dados a qualquer momento.
